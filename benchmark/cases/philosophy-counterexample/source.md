# Why One Counterexample Matters

A universal claim says that every member of a class has a certain property. Because of that form, supporting examples can make the claim more plausible without by themselves proving that no exception exists.

A single genuine counterexample has a different logical role. If an object belongs to the stated class but lacks the stated property, the universal claim is false as written. The key task is therefore to verify both membership in the class and failure of the property.

This asymmetry changes how a disagreement should proceed. Defenders of the universal claim should not answer a candidate counterexample merely by listing more supporting examples; they must show that the candidate does not satisfy the relevant conditions or else revise the claim.
