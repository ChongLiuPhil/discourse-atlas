# 0003 — Small Explicit Relation Ontology

**Status:** Accepted

## Context

A very large relation inventory can reduce consistency and encourage decorative edges.

## Decision

Use the compact canonical set `requires`, `supports`, `derives`, `refines`, `contrasts`, `objects_to`, `responds_to`, `illustrates`, and `sequence`, with explicit direction rules.

## Consequences

New relations require semantic differentiation, direction, examples, and false-positive analysis. Function labels do not automatically become edges. Sparse defensible graphs are preferred.
