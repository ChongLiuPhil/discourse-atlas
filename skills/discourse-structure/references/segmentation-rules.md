# Segmentation Rules

Infer divisions only when the source does not already provide adequate authorial structure.

## Signals for a boundary

A boundary is stronger when several signals coincide:

- a new explicit question or problem;
- a transition from setup to argument, objection, response, application, or conclusion;
- introduction of a new governing claim;
- explicit retrospective or prospective markers (for example, "so far", "I now turn to", "the next question");
- sustained change of argumentative function;
- a cluster of paragraphs that depends internally more strongly than it depends on adjacent paragraphs.

## Weak signals

Do not segment primarily because of:

- paragraph length;
- topic word changes alone;
- a single discourse marker;
- model preference for symmetrical section sizes.

## Naming inferred sections

Use neutral functional titles, for example:

- `Problem formulation`
- `Distinction between X and Y`
- `First argument for the thesis`
- `Objection concerning Z`
- `Response to the objection`
- `Application to case Q`
- `Conclusion`

Do not fabricate literary or authorial-sounding titles.

## Granularity

Choose the coarsest segmentation that still makes the dependency structure intelligible.

Split a unit further only if its internal parts have different discourse functions or meaningful dependency relations.

For long works, analyze recursively:

1. recover top-level divisions;
2. analyze each division;
3. analyze relations among siblings;
4. synthesize the parent;
5. repeat upward;
6. then search for cross-level dependencies.
